Decided to make some common hacking tools "good enough" to bypass Windows Defender as a learning exercise. I have tried to keep the code as similar as possible to the originals to ensure that functionality isn't broken. 

Make sure to change the binary names for each respective tool as this is an IoC in itself (and sometimes detected). If you are lazy, there are some exes built in the bin folders (again, please change the name). Otherwise, you can build it yourself from the slns and change the default namespace & assembly name in the Properties.

No AI was used as this was meant as a learning exercise for me.

Thanks to all of the respective malware authors of the original tools.
